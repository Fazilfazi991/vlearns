V Learns Education Website Package

Files:
- index.html — final one-page website
- assets/ — images, course poster previews, and course PDFs
- CURSOR_PROMPT.txt — prompt to continue improving this in Cursor

How to use:
1. Extract the ZIP.
2. Open index.html in your browser.
3. In Cursor, open the extracted folder.
4. Paste CURSOR_PROMPT.txt into Cursor chat and ask it to refine/build.
5. Deploy as a static website on Vercel, Netlify, Hostinger, or cPanel.

Mobile note:
The HTML is intended as a mobile/iPhone optimized one-page landing page. In Cursor, test especially at 390px and 430px screen widths.
